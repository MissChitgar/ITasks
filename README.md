# iTask — ماتریس زمان و وظایف

اپلیکیشن تک‌صفحه‌ای برای ثبت زمان روی ماتریس **روز × ساعت** با تقویم **شمسی** و رابط فارسی RTL.

## اجرا

فایل `index.html` را در مرورگر باز کنید.

## قابلیت‌ها

- تقویم شمسی (فروردین … اسفند) با تعداد روز درست هر ماه
- جابه‌جایی بین ماه‌ها؛ **داده هر ماه جدا ذخیره می‌شود** و با عوض شدن ماه پاک نمی‌شود
- لیست «ماه‌های ذخیره‌شده» برای برگشت سریع به خرداد، تیر و …
- انتخاب بازه ساعتی با کشیدن ماوس (۲۴ ساعت)
- مدیریت پروژه، گزارش، خروجی Excel و پشتیبان JSON

داده‌ها در `localStorage` مرورگر نگه داشته می‌شوند.
